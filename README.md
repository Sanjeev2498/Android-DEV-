# Android Class Assignments - Complete Collection

This repository contains comprehensive Android class assignments covering fundamental Android development concepts. Each topic is implemented as a separate activity with clean, educational-focused code perfect for learning Android development.

## 📚 Topics Covered

### **Original Class Assignments (5 Topics)**
1. **Student Registration Form** - LinearLayout with form validation
2. **Login Screen** - ConstraintLayout with authentication flow  
3. **Student Profile Screen** - ConstraintLayout with user profile display
4. **City Selection Application** - Spinner implementation with user selection
5. **Programming Language Selection** - CheckBox implementation with multiple selection

### **Additional Advanced Topics (10 Topics)**
6. **Implicit Intent Activities** - URI schemes for web, phone, and maps
7. **Enhanced Student Form** - Complete form with validation and clear functionality
8. **Hello Name App** - Multi-activity Intent data passing
9. **Color Picker App** - Dynamic background color changes
10. **RadioButton Gender Selection** - Gender selection with result display
11. **CardView Example** - Material Design cards with icons and descriptions
12. **Fragment Example** - Dynamic fragment loading and management
13. **Splash Screen** - Professional splash screen with auto-navigation
14. **ListView with Adapter** - List implementation with ArrayAdapter
15. **ViewPager Example** - Swipeable pages with TabLayout indicators

## 🔧 Setup & Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sanjeev2498/Android-DEV-.git
   ```

2. **Open in Android Studio**
   - Open Android Studio
   - Select "Open an existing project"
   - Navigate to the cloned directory
   - Click "OK"

3. **Sync Project**
   - Android Studio will automatically sync Gradle
   - Wait for dependencies to download

4. **Run the App**
   - Connect an Android device or start an emulator
   - Click the "Run" button or press Shift + F10
